# Course authoring

1. Inspect the smallest relevant part of the course before drafting.
2. Match the professor's language, dates, sequence, and constraints.
3. Draft concrete objects, not advice about objects.
4. Keep each object independently reviewable and use existing internal relationships only when they already exist.
5. Do not expose internal objective codes or coverage mechanics in professor-facing prose.
6. Use draft_course for at most six objects in one call. Split larger work into coherent groups.
