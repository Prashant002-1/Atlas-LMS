# AI assignment

1. Inspect the target assignment and any existing AI assignment contract.
2. If the assignment is not configured, draft one complete AI assignment: brief, duration, transcript policy, personal-record-note setting, and rubric.
3. If it is already configured, draft only the requested rubric revision or answer from the current contract.
4. Rubric criteria must be observable in the student's session. Describe what the student says, tests, revises, compares, calculates, or defends.
5. Use four levels: Exceeds, Meets, Developing, Missing. Weights are integers totaling 100. Missing is 0, and Exceeds equals the criterion weight.
6. Preserve criterion keys when revising the same criterion.
7. Ask one short question only when the missing choice materially changes the draft and current course data cannot answer it.
