# Atlas Brand Profile

Atlas is a quiet course-record system for teaching and study. The brand should feel calm, precise, and quietly intelligent: a workspace that lets professors shape a course and lets students practice from the course record without the product narrating itself.

## Motive

Professors already know their course. Atlas gives the course a living structure: objectives, material, datasets, assignments, submissions, and evidence stay attached as the course changes. The product should make that structure feel steady, not busy.

Students need practice that matches what will be assessed. A professor can provide a base dataset or problem frame, then Atlas can generate aligned practice variants from that base. The trust shifts from hand-authoring every exercise to defining the right base and reviewing the course record.

## Personality

- Calm: the interface lowers anxiety and gives the user somewhere stable to work.
- Precise: every visible state should map to a real course record.
- Capable: the product can generate practice and propose course changes, but it does not advertise the machinery.
- Academic: serious, thoughtful, and exact without becoming institutional or bland.
- Quietly premium: distinctive in the small things, restrained in the work surface.

## Visual Direction

The visual language is a quiet generative field behind a rigorous product UI. Think sparse dataset points, course-map traces, small pixel clusters, and fine alignment marks. The atmosphere should be noticed only at rest; while working, it should fall behind the course record.

Use the generated field asset at `public/brand/atlas-field.png` as background atmosphere, not as hero art. It should sit behind panels with low opacity and never reduce contrast.

## Identity System

- Mark: a small pixel/course-map sigil, not a lettermark and not a generic education icon.
- Icons: use standard action icons where clarity matters, but let Atlas-owned micro-glyphs carry identity in quiet record moments.
- Art: generative, data-like, sparse, and calm. No mascots, decorative blobs, stock classroom imagery, or loud illustration panels.
- Texture: almost invisible. It should feel like a field of possible practice variants, not wallpaper.

## Color

- Base: cool neutral workspace background.
- Surface: clean white record panels.
- Ink: charcoal for primary text.
- Accent: restrained teal for current state, progress, and alignment.
- Secondary accent: muted green for completion or confirmed state.

Avoid cream/sand defaults, saturated gradients, and one-note blue dashboards.

## Motion

Motion should be buttery but quiet. Use slow atmospheric drift only in the background, and short 150-250ms transitions for state and controls. Motion should calm, not perform. Respect reduced motion.

## Copy

Assume competence. Do not explain implementation details or reassure users with control language. Prefer short labels tied to course work:

- Good: `Practice base`, `Work`, `Coverage`, `Review`, `Publish`
- Avoid: `AI-generated`, `Professor-controlled`, `agent workflow`, `smart automation`, `implementation`, `demo tenant`

## Product Primitive

Practice bases are part of the course record. A base includes:

- dataset
- concept alignment
- variables
- practice variants
- professor-authored frame

The UI should make this feel like course material, not a prompt-generator feature.
