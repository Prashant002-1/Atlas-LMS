# Course authoring

1. Inspect the smallest relevant part of the course before authoring.
2. Match the professor's language, dates, sequence, and constraints.
3. Create concrete objects, not advice about objects.
4. Use the matching direct action tool when the professor asks to create, edit, publish, or post an ordinary record now.
5. Use draft_course when the professor asks for options, a reviewable set, or a larger coordinated change that belongs in Review.
6. Keep each object independently legible and preserve fields the professor did not ask to change.
7. Do not expose internal objective codes or coverage mechanics in professor-facing prose.
